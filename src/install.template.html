🧁 컵케익 웹리스 백업 풀기 v__RBU_VERSION__

risuai.xyz(웹리스)의 설정 → 계정 & 파일 → 로컬 백업 저장으로 받은 전체 백업(.bin)은 (로그인 상태면 6월부터, v2026.10.210부터는 항상) 암호화돼서, 로컬리스·노드리스·포크 리스에서 불러오지 못해요. 이 도구는 risuai.xyz 페이지 안에서 그 백업의 키를 받아 데이터베이스를 풀고, 어느 리스에서나 불러올 수 있는 일반 백업으로 다시 저장해 줘요.

원본 파일은 바뀌지 않아요. 파일 내용은 브라우저 밖으로 나가지 않고, 키 서버에는 리스 자신과 똑같이 백업 시각만 보내요. 키 서버는 risuai.xyz에서 온 요청만 받기 때문에 꼭 risuai.xyz 탭에서 실행해야 해요.

PC 권장: 데이터베이스를 푸는 동안 DB 크기의 약 3.5~4배 메모리를 써요(400 MB DB → 탭 약 1.7 GB). 데스크톱 앱으로 옮길 거라면 PC에서 바로 하는 게 파일 옮기기도 간단해요. 저장이 끝날 때까지 원본 파일은 옮기거나 지우지 마세요.

1. PC (크롬에서 확인) — 북마클릿

  1. 북마크바를 켜고(Ctrl+Shift+B) 아래 버튼을 북마크바로 끌어다 놓아요.
  2. risuai.xyz 탭에서 그 북마크를 눌러요. 오른쪽 위에 패널이 떠요.
  3. 백업 파일 고르기 → 끝나면 풀린 백업 저장하기.
  4. 옮길 리스에서 설정 → 계정 & 파일 → 로컬 백업 불러오기로 …-unlocked.bin을 열어요.

🧁 웹리스 백업 풀기

엣지·파이어폭스는 아직 직접 확인하지 못했어요.

안드로이드 크롬 기준이에요(실기기 확인 전). iOS는 확인하지 못했어요. 폰에서 푼 파일을 데스크톱 앱에 넣으려면 PC로 옮겨야 해요.

  1. 아래 코드 복사를 눌러요.
  2. 아무 페이지나 북마크로 저장한 뒤, 북마크 수정에서 이름을 백업풀기로, 주소(URL)를 복사한 코드로 바꿔요.
  3. risuai.xyz 탭의 주소창에 백업풀기를 입력하고, 목록에 뜬 북마크(별 모양)를 눌러요.

3. 탬퍼몽키/바이올런트몽키 — 유저스크립트

cupcake-webrisu-backup-unlock.user.js를 열면 탬퍼몽키가 설치 화면을 띄워요. 설치하면 risuai.xyz 왼쪽 아래에 🧁 백업 풀기 버튼이 생겨요.
